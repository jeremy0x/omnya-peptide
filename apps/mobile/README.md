# Omnya Mobile App

Omnya is a sleek, privacy-first protocol companion for peptides, wellness compounds, and metabolic routines.

## Features
- **Daily Dose & Progress Tracking**: One-tap dose confirmation with tactile feedback and cycle awareness.
- **Weekly Photo Reads**: Minimalist studio viewfinder for consistent milestone photography.
- **Inventory & Math**: Built-in reconstitution dilution calculator and vial tracking.
- **Accountability Circles**: Shared streak consistency without revealing sensitive health metrics.
- **Cloud Vault Sync**: Fast, encrypted sync with offline-first local storage.

## Architecture
- **Framework**: Flutter 3.x (Dart 3.x)
- **State Management**: Provider with clean repository/service boundaries
- **Design System**: Liquid Glass, Tactile Haptics, Instrument Sans & Editorial Serif typography
- **Local Database**: Key-value offline-first protocol store
